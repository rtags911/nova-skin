# Page hierarchy

```
Home (/)
├─ Announcement bar — free-shipping offer, seen first
├─ Header — nav (Shop ▾ by category / by concern), search, account, cart
├─ Hero — brand promise, one CTA
├─ Featured products — bestsellers, buy without browsing
├─ Shop by concern — route by skin problem
├─ Benefits — 3–4 trust points
├─ Brand story — why Nova exists
├─ Featured product spotlight — hero SKU, inline add to cart
├─ Testimonials — social proof (marked "Sample")
├─ Promo banner — set / bundle offer
├─ FAQ (short) — remove doubts, link to the full FAQ
├─ Newsletter — capture email
└─ Footer — shop, help, about, socials, policies

Other templates: collection (filters/sort), product, cart (no-JS fallback), search,
about, FAQ, contact, shipping & returns, journal + article, 404, password, customer accounts.
```
