# Brief — NOVA SKIN

- **Business:** premium skincare & beauty DTC brand (fictional, portfolio project).
- **Goal:** a commercial-grade Shopify theme that proves Shopify Developer skills: Liquid, JSON templates, schema, theme blocks, Ajax Cart API, Section Rendering API, facets, metafields, performance, accessibility.
- **Direction:** modern minimalist, luxury, clean type, neutral palette, product photography first, mobile-first.
- **Stack:** custom theme on Shopify's Skeleton theme, vanilla JS Web Components, Shopify CLI, GitHub integration.
- **Apps:** Search & Discovery, Judge.me, Shopify Email (Inbox and GA4 optional).
- **Market:** USD (default, to be confirmed).
- **Sample content to confirm later:** brand name and story, product names, prices, ingredients, testimonials (marked "Sample"), photos (open-licence, credited).
